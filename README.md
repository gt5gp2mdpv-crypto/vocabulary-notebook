# 単語帳PWA

CSVをアップロードして使う、iPhoneホーム画面対応の静的PWAです。IndexedDBに単語帳・暗記スコア・テスト履歴を保存し、JSONバックアップで復元できます。

## 使い方

1. GitHub Pagesなど `https://` で公開してアクセスする（Service Workerの関係上、file://直開きではオフライン機能は動作しません）。
2. メニューの `CSVを追加` から単語帳CSVを追加する。
3. 単語帳カードをタップして開く。`一覧` タブでは単語カードをタップして裏返すと意味が表示される。
4. `テスト` タブで対象を選び `開始` を押すとテストが始まる。
5. 左上の `‹` ボタン、またはメニューの `単語帳一覧` で戻る。

## GitHub Pages公開

1. このフォルダのファイルをGitHubリポジトリに置く。
2. GitHubの `Settings` → `Pages` で公開ブランチを選ぶ。
3. 表示されたURLをiPhone Safariで開き、共有メニューから `ホーム画面に追加` を選ぶ。

## CSV形式

以下の列名をヘッダー自動判定します。

- 英単語: `英単語` / `単語` / `term` / `word` など
- 意味: `意味` / `meaning` / `和訳` / `定義` など
- 番号列: `番号` / `No` などの列は自動的に無視されます（ヘッダーがなくても、先頭列がすべて数値なら番号列として扱います）。

UTF-8とShift_JIS/CP932のCSVに対応します。
